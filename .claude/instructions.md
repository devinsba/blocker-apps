# Project Instructions

## Research Directory

This project contains a `research/` directory with important background information and technical research. When working on tasks related to mobile app development, blocking features, or platform-specific implementations, you should:

1. **Reference the research directory** - Check the research files for relevant technical details, API information, and implementation approaches
2. **Key research files include**:
   - `research/android-blocking-approaches.md` - Android-specific blocking implementation details
   - `research/ios-blocking-approaches.md` - iOS-specific blocking implementation details
   - `research/cross-platform-summary.md` - Cross-platform comparison and recommendations
   - `research/fleet-mdm-report.md` - Fleet/MDM related information

3. **When to consult research**:
   - Before implementing blocking features
   - When making architectural decisions about platform-specific code
   - When troubleshooting platform limitations or capabilities
   - When the user asks about feasibility or approaches for blocking functionality

Always check the research directory for relevant context before making recommendations or implementing features related to app/website blocking, mobile platforms, or MDM capabilities.
